Frequently Asked Questions (FAQ)

What is LumiTorrent?

LumiTorrent is a lightweight, responsive movie exploration interface that integrates YTS metadata with Torbox cloud debrid cache checking. It allows movie enthusiasts to find quality releases and verify instant cloud streaming availability without clutter or advertisements.

How does Torbox instant cache detection work?

By connecting your Torbox API token in Settings, LumiTorrent checks whether release hashes are pre-downloaded across Torbox debrid servers. When a movie displays the green instant badge, it can be downloaded or streamed directly from high-speed cloud servers at uncapped speeds.

Are my API keys and personal data secure?

Yes. LumiTorrent executes entirely on the client side. Your Torbox API token is stored strictly in your browser's local sandbox (localStorage). No user passwords, session tokens, or browsing histories are logged, tracked, or sent to third-party databases.

What is the difference between x264 and x265 releases?

x265 (High Efficiency Video Coding / HEVC) delivers identical or superior picture fidelity at roughly half the file size of traditional x264 encodings. LumiTorrent highlights x265 releases so you can choose optimal storage efficiency and fast streaming.
